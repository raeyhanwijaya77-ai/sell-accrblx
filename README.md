# Roblox Store
1. Upload ke GitHub, import ke Vercel.
2. Vercel > Storage: buat **Neon Postgres** (isi DATABASE_URL) dan **Blob** (token otomatis).
3. Isi Environment Variables sesuai `.env.example`.
4. Pakasir: set Webhook URL ke `https://DOMAIN-KAMU/api/webhook`.
5. Daftar di web memakai Gmail yang sama dengan ADMIN_EMAIL, lalu buka /admin.
